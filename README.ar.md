# 👨‍👩‍👧‍👦  سجل عائلة سلمان — الواجهة الخلفية

[English](README.md) | **العربية**

## نبذة عن المشروع
خادم REST API لنظام سجل عائلة سلمان، مسؤول عن المصادقة والصلاحيات وسجلات الأسر وإعدادات النظام والتصدير إلى Excel والنسخ الاحتياطي لقاعدة البيانات.

## المميزات
- المصادقة باستخدام JWT وتغيير كلمة المرور. يتضمن الـ API إنشاء رمز تحقق وفحصه وإعادة تعيين كلمة المرور؛ أما إرسال الرمز تلقائيًا عبر SMS فهو مخطط له ولم يُربط بمزوّد رسائل بعد. حاليًا توجّه الواجهة المستخدم للتواصل عبر واتساب لاستعادة كلمة المرور.
- صلاحيات مبنية على الأدوار للأدمن ورب الأسرة، مع إدارة دور المشرف وصلاحياته. تتطلب مسارات `/api/admin` حاليًا دور `admin`.
- إدارة بيانات الأسرة والسكن والزوجات والأبناء والبنات المتزوجات والحالات الخاصة.
- رفع الصور الشخصية وإدارة المشرفين والتصدير والنسخ الاحتياطي.
- الحذف المنطقي لسجلات الأسر وإمكانية استعادتها.

## التقنيات المستخدمة
- **الواجهة الخلفية:** Node.js، Express 5.
- **قاعدة البيانات:** MySQL، mysql2، Knex.js للاستعلامات والترحيلات والبيانات الأولية.
- **الأمان:** JSON Web Token وbcryptjs.
- **أدوات إضافية:** Multer، ExcelJS، dotenv.
- **الواجهة الأمامية:** تطبيق React مستقل ([مستودع Frontend](https://github.com/ahalnaji002/Salman-Family-Registry-Frontend)).

## التشغيل المحلي
يتطلب Node.js وnpm وMySQL، كما تتطلب ميزة النسخ الاحتياطي أداة `mysqldump`.

```bash
npm install
cp .env.example .env
```

اضبط ملف `.env` باستخدام `PORT` و`DB_HOST` و`DB_PORT` و`DB_USER` و`DB_PASSWORD` و`DB_NAME` و`JWT_SECRET` و`JWT_EXPIRES_IN`. لا ترفع أسرار التشغيل إلى GitHub.

```bash
npm run migrate
npm run seed  # للتطوير فقط: يتضمن حساب أدمن تجريبيًا ببيانات ثابتة
npm run dev
```

للإنتاج استخدم `npm start`، ولا تستخدم حساب الأدمن التجريبي الناتج عن Seeder في الإنتاج. يمكن إنشاء حساب أدمن باستخدام `node scripts/createAdmin.js` بعد توفير `ADMIN_FULL_NAME` و`ADMIN_NATIONAL_ID` و`ADMIN_PHONE` و`ADMIN_PASSWORD` ومتغيرات قاعدة البيانات في بيئة العملية. ملف السكربت لا يحمّل `.env` بنفسه.

## التحقق وصيانة قاعدة البيانات
لا يتضمن `package.json` الحالي اختبارات آلية بأمر `test`. لفحص حالة الترحيلات:

```bash
npm run migrate:status
```

يطبّق `npm run migrate` الترحيلات، بينما يتراجع `npm run migrate:rollback` عن دفعة منها. كلا الأمرين يغيّر قاعدة البيانات، ولا يُعدّ اختبارًا؛ استخدمهما عند الحاجة مع نسخة احتياطية وفي البيئة المناسبة. بعد تشغيل الخادم يمكن فحص `GET /api/health`.
